Learning Packets

Learning packets are kept in your Google Drive. Do the one-time setup below, then paste the link here.

1 · Google Drive connection

One-time setup guide (about 10 minutes)
  1. Sign in to the Google account that will keep the files. A school Gmail account is recommended (DepEd accounts may block public links).
  2. Open script.google.com → New project. Name it ECES Learner Corner.
  3. Delete the sample code, then paste the whole ECES Google Drive Script file (it is already set to SCHOOL = "ECES", packets only). Click 💾 Save.
  4. In the top bar choose the function setup and click ▶ Run. Click Review permissions → choose the account → Advanced → Go to ECES Learner Corner → Allow.
  5. Click Deploy → New deployment → ⚙️ Web app. Set Execute as: Me and Who has access: Anyone → Deploy.
  6. Copy the Web app URL (ends with /exec), paste it above, click Test connection, then Save.

Setup creates the folder ECES Learning Packets in your Google Drive, with a folder for each grade — put the packets there.

How teachers use it

  • Add books: upload PDF files (they open as page-flip books), E-Book Maker .html files (they open as interactive e-books), or Word/PowerPoint files into ECES Learning Packets › Grade in Google Drive. You may make subfolders like Quarter 2 or Mathematics. They appear on the website within 5 minutes.
  • Remove a packet: delete it from the Drive folder.
  • Other teachers can add packets if you share the ECES Learning Packets folder with them as Editor in Google Drive.

Save straight to GitHub

Changes go live in 1–2 minutes. Needs a GitHub token (see steps below).

How to get a GitHub token (one time)
  1. On GitHub, click your photo → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name it "ECES Site Editor" and pick an expiration date.
  3. Repository access: Only select repositories → choose eces-infosite.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Click Generate token and copy it. Keep it private, like a password.
No token needed

Download the files

Downloads config.js and school-data.js, which you then upload to GitHub.

On GitHub open your repository → assets → js → Add file → Upload files → drag in both downloaded files → Commit changes.
