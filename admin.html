Save straight to GitHub

Changes go live in 1–2 minutes. Needs a GitHub token (see steps below).

How to get a GitHub token (one time)
  1. On GitHub, click your photo → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name it "ECES Site Editor" and pick an expiration date.
  3. Repository access: Only select repositories → choose eces-infosite.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Click Generate token and copy it. Keep it private, like a password.
No token needed

Download the files

Downloads config.js and school-data.js, which you then upload to GitHub.

On GitHub open your repository → assets → js → Add file → Upload files → drag in both downloaded files → Commit changes.
